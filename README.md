# FileFix

FileFix is a simple and modern web application for working with everyday files directly from the browser.

## Features

- Images to PDF
- Merge PDF files
- Compress PDF files
- Word to PDF
- Drag and drop file upload
- Multiple file selection
- Dark mode
- Responsive design
- Arabic interface
- No account required
